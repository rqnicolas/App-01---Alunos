# App 01 - Alunos

Aplicativo desenvolvido em React Native como atividade de aprendizado.

## Sobre o projeto

Este projeto foi desenvolvido para praticar a criação de aplicativos mobile com React Native, trabalhando principalmente com navegação entre telas utilizando React Navigation.

O aplicativo possui as seguintes telas:

* Home
* Vendas
* Sobre
* Grid de Fotos
* Contato

## Tecnologias utilizadas

* React Native
* JavaScript
* React Navigation
* Expo

## Conceitos praticados

* Criação de componentes
* Organização de telas em diferentes arquivos
* Navegação entre telas
* `Stack.Navigator`
* `Stack.Screen`
* `navigation.navigate()`
* Importação de arquivos e componentes
* Utilização de imagens e assets
* Estilização com `StyleSheet`

## Objetivo

O objetivo do projeto é colocar em prática os conceitos básicos de desenvolvimento mobile com React Native e entender como funciona a navegação entre diferentes telas de um aplicativo.
